# Pawdigree Frontend

Frontend application for **Pawdigree**, a pet marketplace connecting customers with verified pet vendors and pet-care services.

## Tech Stack

* React
* TypeScript
* Vite
* ESLint

## Development

The frontend is currently under development as part of the Pawdigree apprenticeship project.

The application will provide interfaces for:

* Customers
* Vendors
* Pawdigree administrators

## Project Structure

The frontend will be developed as a separate application from the Pawdigree Django backend.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
